# 第 3 次上課筆記

- 日期：2026/09/29
- 講者：蕭育仁教授
- 題目：微型氣體感測器產品設計開發

## 筆記內容

這次教授介紹他們團隊開發的 MEMS 微型氣體感測器，從應用需求、感測原理、元件設計與製作、實驗室和工廠的實測，一路講到成立新創公司把技術商品化。

### 1. 氣體感測器的應用與市場需求
- 生活中很常見，例如酒測、一氧化碳中毒警報、會議室二氧化碳監控、甲醛等揮發性有機物（VOC）監測。
- 很多工安事故都跟氣體外洩沒有及時發現有關，例如高雄氣爆（32 人死亡、321 人受傷）、屏東高爾夫球工廠大火（10 死 111 傷）。
- 趨勢是從固定式的「空間偵測」，變成可以帶在身上、以「人」為中心的偵測，所以感測器要小、省電、便宜，才能大量佈建。
- 全球氣體感測器市場 2022 年約 9.8 億美元，預估 2031 年成長到 17.4 億美元，年複合成長率約 6.6%。

### 2. 氣體感測原理與材料
- 最早的氣體偵測是礦工帶金絲雀下礦坑，金絲雀昏倒就代表有危險氣體。
- 金屬氧化物半導體式感測器：感測薄膜加熱到特定溫度後，氣體吸附會改變導電率，再把電阻變化換算成氣體濃度。
- 主要挑戰有三個：靈敏度、選擇性（分得出是哪種氣體），以及反應速度與穩定性。
- 最常用的材料是 SnO₂，其次是 ZnO；不同氣體要搭配不同感測膜，例如 CO 用 SnO₂+Au、NO₂ 用 WO₃。
- 團隊用銀摻雜氧化鋅偵測硫化氫，並用共濺鍍製作薄膜，成分比較均勻、參數容易調整、成本也比較低。

### 3. MEMS 感測元件的設計與製作
- 元件結構包含白金加熱器、白金感測電極、二氧化矽／氮化矽支撐層，背面再蝕刻挖空，減少熱散失。
- 用 ANSYS 模擬三種加熱器圖案：直線 5.61 mW、雙螺旋 3.9 mW、曲折 7.83 mW，比較溫度分布和受熱變形。
- 在國研院半導體中心（TSRI）用 6 吋晶圓製作，製程超過 40 道步驟；一片約需 8,910 分鐘，可產出約 2,000 顆裸晶。
- 實際量測加熱到 300°C 只需要約 53 mW。

### 4. 實驗室與實際場域的驗證
- 一氧化碳 5～25 ppm 的量測結果呈線性關係（R² 約 0.95）。
- 在儀科中心和國際大廠感測器比較，團隊感測器功耗只有約 9～11 mW（市售產品約 0.9 W），反應速度也比較快。
- 在帆宣竹南廠連續監測 5 天，每 10 秒一筆，共 33,301 筆資料；數據上傳到雲端，可以用網頁或手機即時看圖表。
- 也在合作廠商的真空退火爐旁邊長期量測，和市售的 SGP40、MQ138 做比較。
- 還把感測器裝在自走車上，在無塵室邊移動邊偵測氣體，同時繪製地圖和自動避障。

### 5. 技術優勢與新創公司
- 市售感測器的痛點：功耗高（MQ138 約 850 mW、TGS2602 約 280 mW）、加熱不均勻、靈敏度低且反應慢。
- 團隊的感測器面積只有 0.43 mm²，功耗約 11 mW，反應時間約 9.5 秒，偵測範圍 0.5～50 ppm。
- 目前有 8 項專利：5 項是高科大技轉、2 項是金屬中心授權、1 項申請中。
- 新創公司 OMX 規劃四種產品：微型加熱器（已經出貨）、VOC 氣體感測器、VOC 感測模組、陣列式氣體驗證模組。
- 2026～2030 年的規劃是從 VOC 和酒精感測器開始，再擴展到氫氣、乙烯、硫化氫、氨氣，也會提供鍍膜製程和校正驗證服務。

## 名詞解釋

| 名詞 | 英文 | 解釋 |
|---|---|---|
| 微機電系統 | MEMS | 用半導體製程做出來的微小機械與電子元件 |
| 金屬氧化物半導體式感測器 | MOS Gas Sensor | 靠感測薄膜吸附氣體後電阻改變來偵測氣體 |
| 揮發性有機化合物 | VOC | 容易揮發到空氣中的有機物，例如甲醛、苯 |
| 靈敏度 | Sensitivity | 感測器對氣體濃度變化的反應大小 |
| 選擇性 | Selectivity | 感測器分辨不同氣體的能力 |
| 響應時間 | Response Time | 接觸氣體後，訊號達到穩定所需的時間 |
| 微加熱器 | Micro-heater | 把感測薄膜加熱到工作溫度的小型加熱元件 |
| 共濺鍍 | Co-sputtering | 同時用多個靶材鍍膜，可以調整薄膜成分比例 |
| 背蝕刻 | Back Etch | 把晶片背面挖空，減少熱量散失、降低功耗 |
| 有限元素模擬 | ANSYS | 用電腦模擬元件的溫度分布與受力變形 |
| 百萬分之一 | ppm | 氣體濃度單位 |
| 年複合成長率 | CAGR | 一段期間內平均每年的成長比例 |
