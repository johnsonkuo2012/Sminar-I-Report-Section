## 筆記內容

### 1. 教授背景介紹

- 研究專長：

  - 半導體元件物理
  - 表面科學、材料分析與材料製程
  - 電性量測分析

### 2. 何謂綠色科技
- 宗旨：節能減碳、降低能源消耗、減少空氣汙染。
- 範圍包括：
  1. 綠色能源：太陽能
  2. 綠色食品：有機、無農藥
  3. 綠色交通：腳踏車
  4. 綠色建築
  5. 綠色照明：發光二極體
  6. 綠色材料：水、樹葉、氧化鋅材料
  7. 綠色家電：例如 Motorola 可自動分解的手機
- 綠色交通是指低汙染、低噪音、省能源的交通方式，例如電動車、腳踏車、搭公車、坐捷運。
- 電動車的缺點：電池壽命、電池價格、電池汙染。

### 3. 綠色科技相關的光電元件
- 本次演講介紹三種：太陽能電池（solar cell）、發光二極體（LED）、光偵測器（photodetector）。
- 太陽能的優點：節能、環保、屬於再生能源。

### 4. 太陽能電池的種類
- 單結晶矽太陽電池：效率最高。
- 多結晶矽太陽電池：比單晶便宜，表面看得到一塊一塊的晶粒。
- 非結晶矽太陽電池：價格最便宜。

### 5. 太陽能電池的發電原理
- 太陽能電池是由 n 型半導體和 p 型半導體接在一起做成的（p-n 接面）。
- 兩邊接觸的地方會形成空乏區，產生內建電場。
- 太陽光照進來會產生電子電洞對，內建電場會把電子推往 n 型、電洞推往 p 型。
- 接上外部電路後，電子就會流過負載（例如燈泡），形成電流。

### 6. 染料敏化太陽能電池（DSSC）
- 由瑞士洛桑聯邦理工學院（EPFL）的研究團隊在 1991 年發展出來，是一種染料敏化奈米薄膜電池，光電轉換效率達到 7.1%（AM1.5）。
- 結構：ITO 導電玻璃／TiO₂ 奈米薄膜／染料／I₃⁻/I⁻ 電解液／ITO 對電極。
- 運作流程：
  1. 染料吸收光後變成激發態。
  2. 激發態染料把電子注入 TiO₂，染料本身被氧化。
  3. 氧化的染料從電解液中的 I⁻ 拿回電子，恢復原本的狀態，I⁻ 變成 I₃⁻。
  4. 電子經過外部電路到對電極，把 I₃⁻ 還原回 I⁻，完成一個循環。
- 投影片上的元件數據：Jsc 約 12～13 mA/cm²、Voc 約 0.68～0.73 V、FF 約 0.62～0.70、效率約 5.5～6.0%。

## 名詞解釋

| 名詞 | 英文 | 解釋 |
|---|---|---|
| 綠色科技 | Green Technology | 以節能減碳、減少汙染為目標的科技 |
| 太陽能電池 | Solar Cell | 把光能直接轉換成電能的元件 |
| 單晶矽 | Monocrystalline Silicon | 整塊只有一個晶體結構的矽，效率高但比較貴 |
| 多晶矽 | Polycrystalline Silicon | 由很多小晶粒組成的矽，比單晶便宜 |
| 非晶矽 | Amorphous Silicon | 原子排列沒有規則的矽，效率較低但最便宜 |
| 內建電場 | Built-in Electric Field | p-n 接面處自然形成的電場，可以把電子和電洞分開 |
| 染料敏化太陽能電池 | Dye-Sensitized Solar Cell, DSSC | 用染料吸光、TiO₂ 傳電子的太陽能電池 |
| 光電轉換效率 | Efficiency, η | 照進來的光能有多少比例變成電能 |
| 超大型晶圓廠 | Terafab | 馬斯克在德州蓋的晶圓廠計畫，生產自家公司要用的 AI 晶片 |
