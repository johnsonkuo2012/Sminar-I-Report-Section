# 第 2 次上課筆記

- 日期：2026/09/22
- 講者：彭徐鈞教授
- 題目：From Data-Driven Insights to Clinical Translation: Advances in AI for Diagnostic and Prognostic Medical Imaging（從數據驅動到臨床轉譯：人工智慧於醫學訊號診斷與預後評估之最新進展）

## 筆記內容

這次教授介紹了他們團隊用 AI 做的四個醫療研究，大部分都是用病人治療前的影像或訊號，來預測之後的治療結果。

### 1. 使用深度學習模型預測特發性黃斑上膜手術後的視覺預後
- 黃斑上膜是常見的視網膜疾病，手術後不一定每個人的視力都會變好。
- 用手術前的 OCT 影像訓練深度學習模型（ResNet-101 等等），預測術後一年的視力會不會有明顯的進步。
- 模型準確率大約 92%，比參與比較的眼科醫師還高。
- 可以幫醫生判斷病人要不要轉診，以及要不要開刀。

### 2. 以形態定量與放射組學分析預測兒童幕上低級別膠質瘤相關癲癇
- 從 MRI 影像取出腫瘤的位置、形狀和紋理等特徵，再用機器學習預測。
- 腫瘤長在顳葉的小朋友比較容易有癲癇。
- 位置加上放射組學特徵一起用，預測效果最好（準確率約 94%）。

### 3. 使用腦電圖與機器學習預測憂鬱症藥物的長期療效
- 收集憂鬱症患者剛開始吃藥時（第 0、1 週）的腦電圖，預測第 4、6、8 週藥物有沒有效。
- 準確率大約 73%～83%。
- 如果能早點知道藥有沒有效，病人就不用花很久時間一直換藥。

### 4. 基於 nnU-Net 與 MRI 放射組學之聽神經瘤立體定位放射手術後長期治療反應預測
- 用 nnU-Net 自動在 MRI 上把腫瘤圈出來，準確度約 91%。
- 再用機器學習分兩階段預測：先判斷伽瑪刀治療後腫瘤會不會縮小，再判斷是直接縮小還是偽進展。
- 偽進展是腫瘤先變大再縮小，這種比較難預測。
- 團隊有做出一個操作介面，醫生可以直接放入影像看預測的結果。

## 名詞解釋

| 名詞 | 英文 | 解釋 |
|---|---|---|
| 黃斑上膜 | Epiretinal Membrane, ERM | 視網膜表面多長出一層膜，會讓視力變差、看東西變形 |
| 光學相干斷層掃描 | OCT | 拍攝視網膜切面的眼科檢查 |
| 腦電圖 | EEG | 記錄大腦電波的檢查 |
| 深度學習 | Deep Learning | 讓電腦從大量資料中自己學出規則的 AI 方法 |
| 機器學習 | Machine Learning | 用資料訓練電腦做預測或分類的方法 |
| 放射組學 | Radiomics | 從醫學影像中取出大量數值特徵來分析 |
| 聽神經瘤 | Vestibular Schwannoma | 源自第八對顱神經（前庭神經）的良性腫瘤 |
| 伽瑪刀 | Gamma Knife | 用放射線精準照射腫瘤的治療方式 |
| 準確率 | Accuracy | 模型預測正確的比例 |
| 外部驗證 | External Validation | 用別家醫院的資料測試模型，確認模型到別的地方也能用 |
